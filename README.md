# Baltimore Heritage trail map (public copy)

Single-page, self-contained copy of the Baltimore Heritage trail map (D3 bundled). Served by GitHub Pages so viewers need no Google account.
Source and build live in the private repo aaronasorensen/Baltimore-Heritage (`trail-map/make_embed.py`). This repo holds only the built `index.html`.

Link preview: `index.html` carries description and Open Graph tags, and `preview.png` (1200x630) is the image social sites show when the link is shared. If `make_embed.py` rebuilds `index.html`, it must keep those tags.
